\doxysubsection{Detailed Description}
Concrete transport that exchanges frames with a cloud endpoint. 

Typical flow\+:
\begin{DoxyItemize}
\item Construct with the base URL, an authorization header value, and a timeout.
\item Call \doxylink{class_cloud_transport_a4ec99da3109aa4b9f167b7e9d01b3005}{exchange} to POST/\+PUT the request bytes and receive response bytes. 
\end{DoxyItemize}
