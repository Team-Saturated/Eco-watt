\doxysubsection{Detailed Description}
Manages batch uploads of inverter data to cloud endpoints. 

The \doxylink{class_uploader}{Uploader} class handles the transmission of buffered inverter data to cloud APIs. It supports two upload modes\+:
\begin{DoxyItemize}
\item RAW mode\+: Uploads each \doxylink{namespace_modbus}{Modbus} frame as individual JSON objects with hex encoding
\item DECODED mode\+: Uploads batches of decoded register values as consolidated JSON
\end{DoxyItemize}

Includes comprehensive metrics tracking and HTTP status monitoring for debugging and system health monitoring.
