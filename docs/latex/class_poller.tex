\doxysubsection{Detailed Description}
Manages periodic polling of inverter data with error handling and buffering. 

The \doxylink{class_poller}{Poller} class orchestrates regular data acquisition from solar inverters, implementing robust error handling with exponential backoff for failed requests and automatic buffer management with periodic flushing.
