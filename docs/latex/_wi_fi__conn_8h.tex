\doxysubsection{Detailed Description}
Wi\+Fi connection management utilities for ESP32/\+ESP8266 platforms. 

This file provides cross-\/platform Wi\+Fi connection functions that work with both ESP32 and ESP8266 microcontrollers. Handles initial connection establishment and connection monitoring for the Eco\+Watt system.
