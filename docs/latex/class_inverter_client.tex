\doxysubsection{Detailed Description}
High-\/level client for inverter communication operations. 

The \doxylink{class_inverter_client}{Inverter\+Client} class abstracts the complexity of different transport protocols (RS485 \doxylink{namespace_modbus}{Modbus}, HTTP APIs, etc.) and provides a unified interface for reading holding registers from solar inverters.
