\doxysubsection{Detailed Description}
Fixed-\/capacity FIFO ring buffer for \doxylink{struct_record}{Record} objects. 

The buffer overwrites the oldest items when full (drop-\/on-\/overflow policy). Use dropped\+Count to track how many items were overwritten.
