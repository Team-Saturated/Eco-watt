\doxylink{namespace_modbus}{Modbus} protocol utilities and frame processing functions. 

This file provides low-\/level \doxylink{namespace_modbus}{Modbus} protocol utilities including CRC calculation, frame construction for reading holding registers, and data conversion functions for hexadecimal encoding/decoding.
