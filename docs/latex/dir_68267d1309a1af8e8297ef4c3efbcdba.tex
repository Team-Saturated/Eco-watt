This repo contains a minimal scaffold that models\+:
\begin{DoxyItemize}
\item periodic polling of an {\itshape Inverter SIM} (simulated here)
\item buffering samples in RAM
\item a periodic upload window (every 15 seconds, simulated)
\end{DoxyItemize}

It is structured for easy porting to ESP8266/\+Node\+MCU (Arduino core).\hypertarget{README.md_autotoc_md1}{}\doxysubsection{\texorpdfstring{How to use (Arduino IDE / Platform\+IO)}{How to use (Arduino IDE / Platform\+IO)}}\label{README.md_autotoc_md1}

\begin{DoxyItemize}
\item {\bfseries{Board}}\+: Node\+MCU 1.\+0 (ESP‑12E Module) or any ESP8266 board
\item {\bfseries{Framework}}\+: Arduino
\item Open {\ttfamily src/\+Eco\+Watt\+\_\+\+M1.\+ino}
\item Flash. Open Serial Monitor at 115200 baud.
\item You should see samples polled every 2s and an upload printout every 15s.
\end{DoxyItemize}\hypertarget{README.md_autotoc_md2}{}\doxysubsection{\texorpdfstring{Petri Net}{Petri Net}}\label{README.md_autotoc_md2}
