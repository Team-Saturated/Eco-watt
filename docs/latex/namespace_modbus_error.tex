\doxysubsection{Detailed Description}
Namespace containing \doxylink{namespace_modbus}{Modbus} exception codes and error handling utilities. 

This namespace provides standardized exception codes as defined in the \doxylink{namespace_modbus}{Modbus} specification, along with utility functions to convert numeric error codes into descriptive human-\/readable messages.

Convert \doxylink{namespace_modbus}{Modbus} exception code to human-\/readable description. 

Translates numeric \doxylink{namespace_modbus}{Modbus} exception codes into descriptive Flash strings for error reporting and debugging purposes. Uses Arduino\textquotesingle{}s F() macro to store strings in program memory to conserve RAM.
