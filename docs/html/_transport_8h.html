Detailed Description

Transport layer abstraction for Modbus communication protocols.

This file defines the transport layer interface and data structures used for communicating with solar inverters through various protocols (RS485, HTTP/Cloud APIs, etc.). It provides a unified interface for different transport implementations.

Error classification enumeration for actionable error handling.

Categorizes different types of errors that can occur during transport operations, enabling appropriate error handling and recovery strategies.

Enumerator
NONE 

No error occurred, operation successful.

HTTP 

HTTP protocol error (network, server response, etc.)

CRC

TIMEOUT 

Operation timed out waiting for response.

No data received or empty response.

MODBUS_EXC
