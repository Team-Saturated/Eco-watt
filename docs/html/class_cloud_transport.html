Detailed Description

Concrete transport that exchanges frames with a cloud endpoint.

Typical flow:

  • Construct with the base URL, an authorization header value, and a timeout.
  • Call exchange to POST/PUT the request bytes and receive response bytes.

Exchange Modbus request/response through the transport layer.

Sends a complete Modbus request frame and receives the response through the specific transport implementation (RS485, HTTP, etc.). The request should be a properly formatted Modbus frame with CRC for RTU transports.
