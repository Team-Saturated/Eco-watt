Detailed Description

Manages batch uploads of inverter data to cloud endpoints.

The Uploader class handles the transmission of buffered inverter data to cloud APIs. It supports two upload modes:

  • RAW mode: Uploads each Modbus frame as individual JSON objects with hex encoding
  • DECODED mode: Uploads batches of decoded register values as consolidated JSON

Includes comprehensive metrics tracking and HTTP status monitoring for debugging and system health monitoring.

bool Uploader::uploadBatch ( std::vector< Record > & batch)

Upload a batch of records to the cloud.

Processes and uploads all records in the provided batch according to the configured upload mode (UPLOAD_MODE from Config.h). The batch vector is drained/cleared after successful upload.

Parameters
batchVector of records to upload (will be cleared on success)
Returns
true if all items were sent successfully or batch was empty, false on error
Note
Batch size is limited by MAX_BATCH_BYTES configuration parameter
See also
Config.h for UPLOAD_MODE and MAX_BATCH_BYTES settings
