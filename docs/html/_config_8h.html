Detailed Description

Configuration parameters for the EcoWatt solar inverter data acquisition system.

This file contains all the configuration constants used throughout the EcoWatt project, including WiFi credentials, polling intervals, RS485 communication settings, buffer management, upload scheduling, and error handling policies.
