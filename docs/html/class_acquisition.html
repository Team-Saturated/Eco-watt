Perform a single read and decode into a Record.

Reads qty holding registers starting at start from Modbus slave slave. On success, fills out and returns true. On failure, returns false and writes a human-readable message into err.

Parameters
slaveModbus slave address (1–247).
startStarting register address.
qtyNumber of consecutive registers to read.
[out]outDecoded record on success.
[out]errError description on failure.
Returns
true on success, false on failure.
