Detailed Description

Namespace containing Modbus protocol utilities and helper functions.

This namespace provides essential Modbus protocol functions including CRC16 calculation, frame construction for reading operations, and data format conversion utilities for debugging and communication.

Constructs a complete Modbus RTU frame for reading holding registers, including slave address, function code, register address, quantity, and CRC16 checksum.

Calculate Modbus CRC16 checksum for data integrity.

Computes the standard Modbus CRC16 checksum used for error detection in Modbus RTU frames. Uses the polynomial 0xA001 (reverse of 0x8005).

Parameters
dataPointer to byte array to calculate CRC for
lenNumber of bytes in the data array
Returns
16-bit CRC checksum value (little-endian format)
